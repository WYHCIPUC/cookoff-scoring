## 比赛当天操作 SOP

**赛前（10 月 11 日 16:00 前，主持人 5 分钟）**
1. 打开链接 → 主持人后台 → 输口令 → 「组与菜品」
2. 确认各组：组名、成员（2–3 人）、两道菜名、指定评委代表（组数可随时增删：底部"＋增加一组"、每组卡"删除"；菜名/评委也可出菜后现场再填，填完点"保存本组"）
3. 「评分规则」确认：活动名、活动信息、色 30 / 香 30 / 味 40、去极值、评分期间隐藏分数（口令也可在此修改）

**出菜后（19:00）**
4. 每组出菜时，主持人在「组与菜品」为该组两道菜拍 📷 靓照（榜单和海报会用）
5. 主持人「赛程控制」→ 点 **🔔 开火 · 开始评分**
6. 评委们扫码/点链接 → 「我是评委」→ 选自己组 → 逐菜打分（打错可重打）
7. 想拍照的伙伴进「精彩瞬间」随手上传（选所属组或"现场花絮"）
8. 主持人在「赛程控制」盯交卷状态（6 秒自动刷新），没交齐的现场点名催

**揭晓（20:30）**
9. 全部交齐后点 **🏁 收锅 · 揭晓榜单** → 榜单页彩带雨 + 「吃喝大王」诞生
10. 榜单页点 **🎨 生成结果海报** → 长按保存 → 发群/朋友圈
11. 「精彩瞬间」→ **📚 整理成照片合集**（按组分区 + 前三名徽章）→ 复制链接发群

## 功能总览

- **我是评委**：14 道菜按「色 30 / 香 30 / 味 40」打 1–10 分（匿名、本组回避、去极值、可修改）
- **围观 · 战况与榜单**：全场进度 + 匿名实时动态 + 完整榜单（小组总分=两菜之和、匿名明细、投屏）
- **精彩瞬间**：随手拍上传 → 照片墙/大图 → 照片合集 + 结果海报
- **主持人后台**：队伍/菜品/靓照、评分规则、赛程控制（交卷状态+实时动态）、结果明细（可追责）、清空重评

## 技术说明

- 单文件前端 `public/index.html`，腾讯云开发静态托管 + 文档数据库（匿名登录、前端 SDK 直连、数据实时共享），户外手机流量可用，无自建服务器
- 双模式：正式版注入环境 ID；`?demo=1` 或本地打开为**演示模式**（预置示例数据，仅存本机）
- 数据结构：`cc_config`（配置）/ `cc_scores`（每评委×每菜一条）/ `cc_photos`、`cc_dishphotos`（照片压缩后 base64 直存，无过期无跨域）
- 脚本：`scripts/build-dist.mjs`（构建）、`scripts/setup-cloud.mjs`（云端初始化）、`部署.cmd`（一键重新部署）、`本地预览.bat`（演示）

## 安全边界与注意

- 按"可信小圈子活动"设计（匿名登录 + 前端口令）；主持人口令勿外传
- 测试域名首次访问有腾讯"确定访问"提示页，点一下即可（每台手机一次）
- 万一现场网络故障：评分数据在云端，手机有网就能用；完全断网则本次比赛评分作废（无离线模式）
